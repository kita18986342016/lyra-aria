帮助
快捷键

每个快捷键动作有两个绑定框：左「应用内」在主窗口聚焦时生效；右「全局」无论主窗口是否聚焦都生效（比如在其他软件前台时也能切歌），全局键可用总开关一键停用。

录入方法：点击绑定框后直接按下想要的组合键，支持单个键（如只按 N）；按 Esc 放弃录入，按 Backspace 清除该绑定。全局键会在整个系统范围拦截按键，建议使用 Ctrl+Alt+ 类组合，避免与日常打字或其他软件冲突；若提示「注册失败」，说明该组合键已被其他程序占用，换一个即可。

「恢复默认」会把全部动作的应用内/全局键位还原为出厂设置。键盘上的媒体键（播放/暂停/上一首/下一首）始终可用，不受快捷键设置影响。

基本操作

点击播放条左下角封面可打开歌曲详情，底部控制条支持上一首/播放暂停/下一首与倍速/音量调整。

右侧「歌词」旁可切换桌面歌词与任务栏歌词；点击歌曲行的心形收藏。

搜索与在线

顶栏搜索框支持本地搜索与在线(网易云/酷狗/QQ)搜索；点击筛选漏斗可精细过滤下载状态、来源与音质。

在线搜索回车触发，结果可一键下载或加入歌单。

歌单与批量

左侧「我的歌单」支持新建/导入/重命名/右键管理；拖拽可排序。

列表顶部「批量」进入批量模式，可一次播放/收藏/下载/删除/加入歌单。

账号与登录

设置-账号管理统一管理三个平台：网易云音乐、酷狗音乐、哔哩哔哩，均支持扫码登录与手机验证码登录；网易云/酷狗在登录弹窗顶部切换平台，哔哩哔哩在账号管理行点「登录」。

登录收益：网易云/酷狗解锁推荐页「每日推荐」并支持一键导入账号内歌单；B站按你的账号档位自动获得高音质（高清 192k / 大会员无损）。登录网易云/酷狗/B站后，对应行的「一键导入」可列出账号内歌单，勾选批量导入。

一键导入与原版适配

设置右上「导入歌单」支持粘贴链接：网易云/酷狗歌单链接或纯数字 id、QQ 歌单链接、B站收藏夹链接。

导入时自动适配原版：标题带「变速 / DJ / 翻唱 / 伴奏」等标记的歌会自动去其他平台找原版替换（比对专辑与歌手，找不到才保留）；本源无版权而缺失的歌会提示数量，播放到它们时也会自动尝试其他音源续播，全部无资源则自动跳下一首，不会停在原地。

猜你喜欢

推荐页下方「猜你喜欢」按你常听的歌手自动生成 50 首混合队列：大部分来自你听得最多的歌手，另按「尝新比例」掺入没听过的新歌（设置-常规可调 0~50%，默认 30%）。

双击任意一首即按整批播放；一整批听完会自动生成新一批接着播，也可以点「换一批」手动刷新。不感兴趣可直接双击跳听。

音质说明

设置-音源与音质的「在线播放音质」对网易云/酷狗/QQ 全部生效：标准 128k / 高品 320k / 无损 FLAC，播放时按当前设置向音源请求，实际拿到的档位以歌曲行与底栏标签为准（诚实标注）。

B站歌曲登录后自动跟随账号档位（高清 192k / 大会员 Hi-Res 无损）；个别歌曲音源本身只有低档位时会如实标注，不会虚标。

外观

设置内的主题、强调色、背景氛围与背景强度可实时预览。

更新

新版本启动时自动提示，更新公告小窗可关闭；也可在「软件更新」页手动检查。

性能诊断

播放时 CPU 占用异常？点「一键诊断」采集 GPU/进程/动画数据并复制 JSON，发给开发者定位。
